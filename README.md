# 🏪 منصة مساعدة للتجارة الإلكترونية

منصة شاملة لمساعدة التجار والمتاجر الإلكترونية على إدارة أعمالهم بكفاءة.

## ✨ الميزات الرئيسية

- 👤 **نظام المصادقة والمستخدمين**: تسجيل وتسجيل دخول آمن مع دعم الأدوار المختلفة
- 🛍️ **إدارة المنتجات**: إضافة وتعديل وحذف المنتجات مع تتبع المخزون
- 📦 **إدارة الطلبات**: تتبع الطلبات وحالاتها من الطلب إلى التسليم
- 💳 **نظام الدفع**: معالجة الدفع والفواتير والمحافظ الرقمية
- 📊 **التحليلات والتقارير**: إحصائيات مبيعات وأداء شاملة
- 📈 **لوحة التحكم**: رؤية شاملة للأداء والإحصائيات

## 🛠️ التقنيات المستخدمة

### Backend
- **Node.js**: بيئة تشغيل JavaScript
- **Express.js**: إطار العمل للـ REST API
- **MongoDB**: قاعدة البيانات NoSQL
- **JWT**: المصادقة والتفويض
- **Bcrypt**: تشفير كلمات المرور الآمنة

### Frontend (قريباً)
- React.js
- Redux للإدارة
- Tailwind CSS للتصميم

## 📦 المتطلبات

- Node.js v14+
- MongoDB (محلي أو Atlas)
- npm أو yarn

## 🚀 التثبيت والتشغيل

```bash
# 1. استنساخ المستودع
git clone https://github.com/Mourtamad/BIM.git
cd BIM

# 2. تثبيت المكتبات
npm install

# 3. إنشاء ملف .env
cp .env.example .env

# 4. تحرير ملف .env بالمتغيرات الصحيحة

# 5. تشغيل الخادم
npm start

# للتطوير مع إعادة تحميل تلقائية:
npm run dev
```

## 🔧 إعدادات متغيرات البيئة (.env)

```env
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb://localhost:27017/commerce-helper
JWT_SECRET=your_secret_key_change_in_production
JWT_EXPIRE=7d
FRONTEND_URL=http://localhost:3000
```

## 📚 المسارات الرئيسية للـ API

### 🔐 المصادقة (`/api/auth`)
| الطريقة | المسار | الوصف |
|--------|--------|--------|
| POST | `/register` | تسجيل مستخدم جديد |
| POST | `/login` | تسجيل الدخول |
| GET | `/me` | الحصول على بيانات المستخدم الحالي |

### 🛍️ المنتجات (`/api/products`)
| الطريقة | المسار | الوصف |
|--------|--------|--------|
| GET | `/` | جلب جميع المنتجات |
| GET | `/:id` | جلب منتج واحد |
| POST | `/` | إضافة منتج جديد |
| PUT | `/:id` | تحديث منتج |
| DELETE | `/:id` | حذف منتج |

### 📦 الطلبات (`/api/orders`)
| الطريقة | المسار | الوصف |
|--------|--------|--------|
| GET | `/` | جلب جميع الطلبات |
| POST | `/` | إنشاء طلب جديد |
| PUT | `/:id/status` | تحديث حالة الطلب |

### 📊 التحليلات (`/api/analytics`)
| الطريقة | المسار | الوصف |
|--------|--------|--------|
| GET | `/dashboard/:sellerId` | لوحة التحكم الرئيسية |
| GET | `/products/:sellerId` | إحصائيات المنتجات |
| GET | `/revenue/:sellerId` | تقارير الإيرادات |

### 💳 الدفع (`/api/payments`)
| الطريقة | المسار | الوصف |
|--------|--------|--------|
| POST | `/process` | معالجة الدفع |
| GET | `/history/:sellerId` | سجل الدفع |

### 👥 المستخدمون (`/api/users`)
| الطريقة | المسار | الوصف |
|--------|--------|--------|
| GET | `/` | جلب جميع التجار |
| GET | `/:id` | جلب بيانات مستخدم |
| PUT | `/:id` | تحديث بيانات مستخدم |

## 👥 أنماط/أدوار المستخدمين

| الدور | الأذونات |
|------|----------|
| **user** | تصفح المنتجات، إنشاء طلبات، التقييم |
| **seller** | إضافة منتجات، إدارة طلبات، عرض التحليلات |
| **admin** | إدارة كاملة للمنصة والمستخدمين |
