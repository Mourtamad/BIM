# 🏪 منصة التجارة الإلكترونية المتقدمة
# Commerce Helper Platform - Advanced E-Commerce Solution

منصة متكاملة لتحقيق أقصى أرباح من خلال نماذج ربح متعددة وميزات احترافية.

---

## 💰 **نماذج الربح المتقدمة**

### 1️⃣ **العمولات على المبيعات** (Commission-Based)
```
العمولة = نسبة من كل عملية بيع
مثال: 15% من 200 ريال = 30 ريال ربح للمنصة

التوقع الشهري (1000 طلب):
1000 × 200 × 15% = 30,000 ريال
```

### 2️⃣ **نظام الاشتراكات** (Subscription Model)
```
خطط متعددة:
- خطة مجانية: بدون
- خطة أساسية: 50 ريال/شهر
- خطة احترافية: 150 ريال/شهر
- خطة مؤسسية: 500 ريال/شهر

التوقع: 500 بائع × 100 ريال متوسط = 50,000 ريال/شهر
```

### 3️⃣ **الإعلانات المدفوعة** (Paid Advertising)
```
أنواع الإعلانات:
- متجر مميز: 200 ريال/شهر
- منتج مميز: 100 ريال/شهر
- إعلان بانر: 50 ريال/يوم
- منتج مرقى: 150 ريال/أسبوع

التوقع: 100 إعلان × 150 ريال = 15,000 ريال/شهر
```

### 4️⃣ **الكوبونات والخصومات** (Coupons & Deals)
```
- عرض كوبون مميز: 200 ريال
- عرض فلاش سيل: 300 ريال
- عرض موسمي: 500 ريال

التوقع: 30 عرض × 200 ريال = 6,000 ريال/شهر
```

### 5️⃣ **التقييمات والمراجعات** (Reviews & Ratings)
```
- بيع بيانات التقييمات: 1,000 ريال/شهر
- تقارير الجودة: 500 ريال
```

## 📚 **المسارات الرئيسية للـ API**

### **🔐 المصادقة**
```
POST   /api/auth/register          تسجيل مستخدم جديد
POST   /api/auth/login             تسجيل الدخول
GET    /api/auth/me                الحصول على البيانات الحالية
```

### **💳 الاشتراكات والخطط**
```
GET    /api/subscriptions/plans           جلب جميع الخطط
POST   /api/subscriptions/subscribe       الاشتراك في خطة
GET    /api/subscriptions/my-subscription/:userId    بيانات الاشتراك
POST   /api/subscriptions/cancel/:id      إلغاء الاشتراك
```

### **💰 العمولات والأرباح**
```
POST   /api/commissions/calculate         حساب العمولة
GET    /api/commissions/seller/:sellerId  عمولات البائع
GET    /api/commissions/platform/all      جميع العمولات (Admin)
PUT    /api/commissions/:id/paid         تحديث حالة الدفع
```

### **⭐ التقييمات والمراجعات**
```
POST   /api/reviews/                      إضافة مراجعة
GET    /api/reviews/product/:productId    مراجعات المنتج
PUT    /api/reviews/:id/approve          الموافقة على المراجعة
PUT    /api/reviews/:id/helpful          تحديد كمفيدة
```

### **🎁 الكوبونات والخصومات**
```
POST   /api/coupons/                      إنشاء كوبون
POST   /api/coupons/validate             التحقق من الكوبون
GET    /api/coupons/active               الكوبونات الفعالة
POST   /api/coupons/:id/use              استخدام الكوبون
```

### **📢 الإعلانات**
```
POST   /api/advertisements/               إنشاء إعلان
GET    /api/advertisements/active         الإعلانات النشطة
PUT    /api/advertisements/:id/approve    الموافقة على الإعلان
POST   /api/advertisements/:id/click      تتبع الضغطات
GET    /api/advertisements/:id/stats      إحصائيات الإعلان
```

### **📊 لوحة الأرباح والإيرادات**
```
GET    /api/revenue/platform/revenue      إجمالي الأرباح
GET    /api/revenue/seller/:sellerId      أرباح البائع
GET    /api/revenue/monthly/report        التقرير الشهري
```

### **🛍️ المنتجات والطلبات**
```
GET    /api/products/                     جلب المنتجات
POST   /api/products/                     إضافة منتج
GET    /api/orders/                       جلب الطلبات
POST   /api/orders/                       إنشاء طلب
```

## 🎯 **خصائص المتقدمة**

### **نظام الاشتراكات الذكية**
- ✅ خطط متعددة الأسعار
- ✅ تجديد تلقائي
- ✅ إلغاء سهل
- ✅ تتبع الاستخدام

### **نظام العمولات التلقائي**
- ✅ حساب تلقائي بعد كل عملية
- ✅ معدلات عمولة مختلفة حسب الخطة
- ✅ تقارير شاملة
- ✅ تحويل آمن للأرباح

### **نظام الإعلانات المتقدم**
- ✅ أنواع متعددة من الإعلانات
- ✅ تتبع الأداء (CTR, Impressions)
- ✅ إحصائيات مفصلة
- ✅ موافقة تلقائية/يدوية

### **إدارة الكوبونات**
- ✅ خصومات نسبية وثابتة
- ✅ حد أدنى للطلب
- ✅ حد أقصى للاستخدام
- ✅ تطبيق انتقائي حسب الفئة

### **نظام التقييمات**
- ✅ موافقة على المراجعات
- ✅ حساب التقييم الموحد
- ✅ تحديد المراجعات المفيدة
